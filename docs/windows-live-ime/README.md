# Sumi — Windows日本語IME 設計資料

更新：2026-11-25（日本時間）／方針リビジョン3（Sumiへの移行）  
状態：計画・仕様整理。新IMEの実装、Windowsビルド、Mac実機比較は未実施。  
製品名：Sumi（開発名。商標調査・正式リリース名の確定は未実施）。

Mozkeyを基盤に、macOS標準の日本語入力の操作・表示を忠実に再現するWindows向けIMEを設計する。設定画面は**初版からWinUI 3**で実装する。

## 今回確定した方針

1. **最初の目標はMacの入力体験を再現すること。** 独自のキー操作を先に決めず、基準Macの実測結果に合わせる。
2. 基準設定は、日本語ローマ字入力、ライブ変換ON、Windows風キー操作OFF、推測候補表示OFFとする。macOS版・配列・その他設定は実機記録で固定する。
3. **設定画面をQtのまま出荷して後でWinUIへ移す案は採用しない。** 初版の通常設定導線をWinUI 3で完結させる。
4. 変換エンジンとTSFは既存C++を活用する。Rustへの部分移行は、同条件の性能比較で判断する。
5. Store公開を目標に、サービス依存、署名、ライセンス、更新・削除を初期段階から確認する。

「Macを再現する」の対象は、キーごとの状態遷移、候補表示、文節編集、確定・取消、モード切替、タイミングと外観。候補の語彙・順位・変換精度はMozc/Zenzに依存するため、Appleの変換エンジンと同一であるとは扱わない。詳細は互換仕様で判定を分ける。
