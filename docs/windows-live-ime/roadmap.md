設計文書のみ作成済み。以下の実装・実機検証は未着手。

## 1. 段階と完了条件

| 段階 | 内容 | 成果物・完了条件 |
| --- | --- | --- |
| P0：基準記録 | MacのOS・設定・配列を固定し、キー操作を記録。未改変MozkeyをWindowsでビルド・計測 | Mac参照記録、互換性マトリクス、性能基準と許容値、Store制約一覧 |
| P1：接続試作 | 新IMEの識別子と保存先を分離。WinUI 3/C++バックエンドの小さい接続を作る | 元Mozkeyと共存。WinUIで1項目を読込み・保存し、再起動後も反映 |
| P2：Mac操作 | 読み、ライブ変換、候補、文節、確定・取消、モード切替を実装 | 主要なMac記録ケースで操作状態が一致 |
| P3：WinUI設定 | 一般、外観、キー、辞書、AI、学習、ライセンスを実装 | 通常設定をWinUIだけで完結。保存失敗・競合・移行も確認 |
| P4：候補とアイコン | 参照Macに基づいて既存描画を調整。小さいモードアイコンも作る | 実機比較、DPI、テーマ、アプリ内描画経路を確認 |
| P5：省メモリ | 不要生成・AIの寿命・常駐・資源を改善。必要ならRust試作 | 同条件の測定で採用／見送りを記録 |
| P6：実用確認 | ARM64/x64と主要アプリで入力・更新・削除を検証 | 重大な入力不具合・設定消失がなく、差分が記録されている |
| P7：配布 | ライセンス、署名、MSI、掲載情報、審査上の論点を整備 | 署名済み成果物。条件が整えばStore申請 |

P0のMac記録とWindowsの基準計測は並行可能。P1後はMac操作とWinUI画面を並行開発できる。Rust検討はWinUI 3初版対応やMac互換を後回しにする理由にしない。

## 3. 最初に動かす試作

P0/P1の最初の試作では、次を確認する。

1. 参照MacのSpace、Enter、Esc、Backspace、文節移動の記録がある。
2. 新IMEが元Mozkeyと共存する。
3. その記録に従うライブ変換と候補表示をWindowsで試せる。
4. WinUI 3で設定を読み、変更し、保存できる。
5. 設定画面を閉じた後の通常入力で設定プロセスが常駐しない。

これは完成品ではなく、主要な技術選択を確認する試作。全画面の実装、辞書機能、外観仕上げ、配布検証は後続の完了条件を満たす。
